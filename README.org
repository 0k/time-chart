#+title: @0k/time-chart

Linked, zoomable time-series charts for the browser, built on
[[https://echarts.apache.org/][Apache ECharts]]. No framework required.

- Day, month and year guides that fade in with zoom, weekends hatched,
  and a "now" line; all in local time, correct across DST changes.
- Wheel zoom and drag pan on the time axis; charts sharing a ~link~ key
  zoom together.
- Stacked areas, min/max bands and gaps for missing values.
- Light and dark themes, following the OS by default.

* Install

#+begin_src sh
npm install @0k/time-chart
#+end_src

* Usage

#+begin_src typescript
import { createTimeChart } from '@0k/time-chart';

const now = Date.now();
const chart = createTimeChart(document.getElementById('chart')!, {
  series: [{
    id: 'sensor-a',
    label: 'Sensor A',
    points: [[now - 3_600_000, 2], [now, 3]],
  }],
  formatValue: value => value.toFixed(2),
  onWindowChange: (start, end) => { /* fetch data for this window */ },
});

chart.setSeries(newSeries);   // keeps the current window and hidden series
chart.setWindow(start, end);
chart.destroy();
#+end_src

The element must have a nonzero size. Times are Unix milliseconds.

* Series

| Field          | Description                                                  |
|----------------+--------------------------------------------------------------|
| ~id~           | Unique identifier                                            |
| ~label~        | Name shown in the legend and tooltip                         |
| ~points~       | ~[time, value]~ pairs sorted by time; ~null~ value is a gap  |
| ~min~, ~max~   | Optional band bounds, one per point                          |
| ~group~        | Series of a group get close colors                           |
| ~stack~        | Stack with the other stacked series                          |
| ~color~        | Explicit CSS color instead of the generated one              |
| ~dash~         | ~'solid'~ (default), ~'dashed'~ or ~'dotted'~ line style       |
| ~width~        | Finite positive line width in pixels (default 1); highlighting doubles it, dimming halves it |
| ~fill~         | Opacity in ~(0,1]~; fill to the bottom of the y axis, not stacked; cannot be combined with ~stack: true~ |
| ~band~         | ~{pattern, opacity}~ for ~min~ / ~max~ bounds; ~pattern~ is ~'solid'~ (default) or diagonal ~'hatch'~ in the series color; ~opacity~ is in ~(0,1]~ (default 0.18) |
| ~line~         | Draw the line (default ~true~); ~false~ keeps its band/fill and legend entry but excludes it from the tooltip |

* Options

| Option           | Default             | Description                                    |
|------------------+---------------------+------------------------------------------------|
| ~series~         | required            | Series to draw                                 |
| ~window~         | data extent         | Initial ~{start, end}~ shown                   |
| ~formatValue~    | localized number    | Formats y-axis labels and tooltip values       |
| ~formatTime~     | localized date/time | Formats the tooltip time                       |
| ~yAxis~          |                     | ~{min, max, name, interval, minorInterval}~; ~max: 'data'~ fixes it at 1.2 × data maximum (default) |
| ~yAxis.interval~ | automatic           | Finite positive major tick and label step |
| ~yAxis.minorInterval~ | disabled       | Finite positive minor tick step with dashed minor split lines; requires ~interval~ and must divide it into an integer count from 2 to 99 |
| ~tooltip~        | ~'axis'~            | ~'axis'~ (all series) or ~'item'~ (one)        |
| ~legend~         |                     | ~{show, collapsed, width, maxWidth}~, scrolls, on right |
| ~legend.width~   | ~340~               | Column width in pixels, or ~'auto'~ to fit the widest label |
| ~legend.maxWidth~ | ~240~ for ~'auto'~ | Caps the column; when set, also caps a numeric ~width~ |
| ~link~           |                     | Charts with the same key zoom, pan and hover together by time; their ~'auto'~ legends share the widest column |
| ~onWindowChange~ |                     | Called after the user zooms or pans            |
| ~onLegendToggle~ |                     | Called when the user toggles a series          |
| ~locale~         | browser locale      | Locale for labels and default formatters       |
| ~theme~          | ~'auto'~            | ~'auto'~, ~'light'~ or ~'dark'~                |

With ~legend: { width: 'auto' }~ the legend column is as wide as its
widest label: at least 80 pixels (less only if ~maxWidth~ is smaller),
at most ~maxWidth~; longer labels are
ellipsized and shown in full on hover. Labels are measured again when
~setSeries~ changes them. Charts sharing a ~link~ key and an ~'auto'~
legend all take the widest column of the group, each within its own
~maxWidth~, so with the same ~maxWidth~ their plots line up;
the group adjusts when one of them changes labels or is destroyed. A
chart with a numeric ~width~ keeps it.

Charts sharing a ~link~ key are linked by time: after a user zoom or pan
they all show the same time window, and hovering one puts the others'
pointers at the same time, even when their data covers different ranges
or different timestamps. With ~tooltip: 'axis'~ each linked chart also
shows its tooltip, with the values of its own points nearest to that
time; with ~'item'~ only the pointer is linked. A chart hides its pointer
when the time is outside the span of its points or outside its window.
~onWindowChange~ fires on every affected chart after 150 ms without
another zoom or pan, with that chart's current window.
~setWindow~ changes only the receiving chart and never fires the callback;
set it on each linked chart when choosing a range programmatically.

* Methods

| Method                     | Description                                   |
|----------------------------+-----------------------------------------------|
| ~setSeries(series)~        | Replace the data                              |
| ~setWindow(start, end)~    | Show this time range (no ~onWindowChange~)    |
| ~getWindow()~              | Current ~{start, end}~                        |
| ~setHidden(ids)~           | Hide these series                             |
| ~highlight(ids)~           | Emphasize these series; ~null~ resets         |
| ~setLegendCollapsed(bool)~ | Hide or show the legend                       |
| ~resize()~                 | Redraw after a size change                    |
| ~destroy()~                | Release the chart; safe to call twice         |

~calendarGuides(start, end, widthPx, now, locale?)~ is also exported: it
returns the guide lines and weekend bands for a time range, without
drawing anything.

* Development

npm install

npm run demo    # http://127.0.0.1:5187/demo/
